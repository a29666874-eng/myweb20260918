# 不動產／地政士 Skills 索引

這個資料夾存放為地政士（兼翡翠山水股東）整理的 Claude Skills。
每個 skill 一個子資料夾，內含 `SKILL.md`（YAML frontmatter：`name`、`description`）。

每日排程任務會從開源資源（GitHub、政府開放資料、法規資料庫等）尋找有用內容，
整理成**候選 skill** 放在 `skills-candidates/`，經地政士本人審核同意後才移入此資料夾啟用。
每日紀錄放在 `docs/research-log/`。

## 主題分類

| 類別 | 範例 |
|------|------|
| 法規 | 土地法、平均地權條例、地政士法、不動產經紀業管理條例、土地登記規則、房地合一稅、公寓大廈管理條例 |
| 登記實務 | 買賣、繼承、贈與、設定抵押、塗銷、書狀補發、規費計算 |
| 稅務 | 土地增值稅、契稅、房屋稅、地價稅、房地合一稅、遺產及贈與稅 |
| 交易模型 | 實價登錄分析、估價方法（比較法／收益法／成本法）、投資報酬、貸款試算 |
| 開發／建案 | 容積、都市計畫、建案財務模型、預售屋規範 |
| 裝潢 | 室內裝修許可、工程估價、建材與工法、驗屋清單 |
