# 候選 Skills（待審核）

每日排程任務產出的新 skill 會先放在這裡，**不會自動啟用**。
由地政士本人審核後決定是否安裝。

## 篩選原則（每個候選都必須通過）
1. **確實有幫助**：對地政士實務或翡翠山水的不動產業務有具體用途，內容經查證，不是空泛或錯誤資訊。
2. **免費**：不需付費、訂閱、試用後收費或付費 API 金鑰。
3. **安全**：不含惡意程式、不明下載、混淆程式碼、會偷傳資料或要求帳號密碼的內容；
   不執行 `curl | sh` 之類的遠端安裝指令，不安裝來路不明的套件。
   附帶的腳本只用 Python 標準庫，或常見且可信的開源套件，並在 skill 中寫明。
4. **授權允許**：開源授權允許再利用，或為政府公開資料／法規條文。

沒通過的，只記在當日研究紀錄的「已排除」欄，並寫明原因，不會放進候選清單。

## 如何安裝
跟 Claude 說「安裝 <skill 名稱>」，Claude 會把資料夾從 `skills-candidates/<名稱>/`
移到 `.claude/skills/<名稱>/` 並更新索引。不要的就說「刪除 <skill 名稱>」。

## 兩種候選
- **業務知識類**：法規、登記、稅務、估價、交易模型、裝潢等，直接給地政士用。
- **助手能力類**：讓 Claude 在工作上更好用的東西，例如處理 PDF／Excel／Word 的方法、
  查詢法規的流程、文件比對、試算表範本、免費的 MCP 工具等。
  這類只會**提案**，寫明它能做什麼、裝在哪、需要什麼權限、有沒有風險，
  經同意後才安裝；一樣必須通過上面四條篩選。
